## 📂 **Installation**

1. **Placez vos 20 images** dans le dossier `public/expressions/`
2. **Vérifiez les noms** exacts (respectez majuscules/minuscules)
3. **Redémarrez le serveur**

## ✅ **Vérification**

Après avoir placé les fichiers :
- Ouvrez `VERIFICATION_EXPRESSIONS.html` dans votre navigateur
- Vous devriez voir **20/20** images trouvées
- Les emojis seront remplacés par vos illustrations
