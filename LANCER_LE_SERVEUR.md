# 🚀 Lancement du serveur AI Idol Companion

## 📋 Fichiers créés

Deux scripts de lancement ont été créés pour votre commodité :

### 1. **start-server.bat** (Fichier Batch Windows)
- Double-cliquez dessus pour lancer
- Compatible avec toutes les versions de Windows
- Interface console traditionnelle

### 2. **start-server.ps1** (PowerShell Windows)
- Plus moderne et coloré
- Meilleure gestion des erreurs
- Exécutez avec : `powershell -ExecutionPolicy Bypass -File .\start-server.ps1`

## 🎯 Utilisation

### Méthode 1: Double-cliquez
1. Allez dans le dossier du projet
2. Double-cliquez sur `start-server.bat`
3. Le serveur démarrera automatiquement

### Méthode 2: PowerShell
1. Ouvrez PowerShell dans le dossier du projet
2. Exécutez : `.\start-server.ps1`
3. Suivez les instructions

### Méthode 3: Manuel
1. Ouvrez un terminal/CMD dans le dossier du projet
2. Exécutez : `npm run dev`

## 🌐 Accès à l'application

Une fois le serveur lancé :
- **Local** : http://localhost:5173
- **Réseau** : http://[VOTRE_IP]:5173
- **Installation PWA** : Accédez via votre mobile sur le même réseau

## ⚡ Vérification

Le serveur est prêt quand vous voyez :
```
Local:   http://localhost:5173/
Network: http://192.168.x.x:5173/
```

## 📱 Installation PWA sur Android

1. Ouvrez Chrome sur votre téléphone
2. Allez à l'URL locale
3. Menu (⋮) → "Ajouter à l'écran d'accueil"
4. L'icône "AI Idol" apparaîtra sur votre écran
